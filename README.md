# BHOOMI-JEEVAN

BHOOMI-JEEVAN is an India-first precision agriculture MVP focused on transparent farmer decision support.

## Phase-1 MVP Included

- Farmer/farm/field profile foundation (demonstration mode)
- Soil health snapshot with reliability classes (`MEASURED`, `OBSERVED`, `ESTIMATED`, `PREDICTED`, `UNAVAILABLE`)
- Weather + crop-water requirement engine
- FAO-56 inspired irrigation recommendation with assumptions and confidence labels
- Actionable farmer recommendations (`what`, `why`, `action`, `when`, `confidence`, `sources`)
- Accessible Apple-style mobile-first dashboard (light/dark support)

> Important: this repository currently runs in **demonstration mode** with clearly labeled mixed data sources. It does not claim fabricated live sensor telemetry.

## Run locally

```bash
npm start
```

Open `http://localhost:3000`.
